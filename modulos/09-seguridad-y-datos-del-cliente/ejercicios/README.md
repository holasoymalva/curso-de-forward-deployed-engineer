# Ejercicios del Módulo 09: Seguridad y datos del cliente

Ejercicios prácticos para evaluar y fortalecer la postura de seguridad y el cumplimiento normativo en implementaciones de Forward Deployed Engineering.

---

## 🎯 Lista de ejercicios

| Ejercicio | Nivel | Enfoque | Archivo a trabajar |
|-----------|-------|---------|--------------------|
| [**01. Auditor de fugas de PII**](01-auditor-de-fugas-de-pii.md) | 🟡 Intermedio | Escaneo automatizado de logs o archivos de datos con expresiones regulares para detectar filtraciones de PII (correos, teléfonos, RFCs). | Script de Python propio |
| [**02. Evaluación de riesgos y cuestionario SOC 2**](02-evaluacion-de-riesgos-y-cuestionario-soc2.md) | 🟡 Intermedio | Análisis de riesgos y redacción técnica formal para responder al cuestionario de seguridad del CISO de Distribuidora Halcón. | Documento Markdown |

---

## 🛠️ Instrucciones de trabajo

1. Para el **Ejercicio 01**, implementa un script en Python que analice archivos de texto o logs en busca de patrones sensibles y reporte las infracciones encontradas.
2. Para el **Ejercicio 02**, asume el rol del FDE principal de Nexo AI y responde de forma rigurosa y transparente a las preguntas formuladas por el auditor de seguridad.
3. Compara tus respuestas y código con las soluciones de referencia en [`soluciones/`](soluciones/).
