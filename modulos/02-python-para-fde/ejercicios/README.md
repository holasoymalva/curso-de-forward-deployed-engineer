# Ejercicios del Módulo 02: Python para FDE

Prácticas de programación en Python orientadas a la limpieza de datos reales, manejo defensivo de errores y construcción de utilidades CLI.

---

## 📋 Lista de ejercicios

| # | Ejercicio | Nivel | Tiempo estimado | Enfoque |
|---|-----------|-------|-----------------|---------|
| 01 | [Normalizador de catálogo de tiendas con PII](01-normalizador-de-csv.md) | 🟢 | 40 min | Sanitización de teléfonos, validación de correos electrónicos y deduplicación. |
| 02 | [CLI de auditoría y detección de anomalías](02-cli-de-auditoria-de-inventario.md) | 🟢 | 45 min | Construcción de una herramienta con `argparse` y reporte de calidad de datos. |

---

## 💡 Instrucciones

1. Crea tus scripts de solución en una carpeta propia de trabajo o en `scratch/`.
2. Utiliza **únicamente la biblioteca estándar de Python** (`csv`, `json`, `re`, `argparse`, `logging`).
3. Compara tu implementación con las soluciones comentadas en la carpeta [`soluciones/`](soluciones/).
