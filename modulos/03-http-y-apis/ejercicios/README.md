Ejercicios prácticos en Python para interactuar con la API simulada de Distribuidora Halcón.

## 💡 Instrucciones

1. Asegúrate de tener corriendo la API simulada:
   ```bash
   python recursos/api-simulada/servidor.py
   ```
2. Realiza tus scripts en Python utilizando la biblioteca estándar (`urllib.request`, `json`).
3. Compara tus programas con las soluciones oficiales en [`soluciones/`](soluciones/).
